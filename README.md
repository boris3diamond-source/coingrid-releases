# Установка Coin Grid

Нужен Mac на Apple Silicon (M1 и новее) с macOS 13 Ventura или новее.

## Три шага

1. **Скачайте** архив `CoinGrid-<версия>-arm64.zip` со страницы
   https://github.com/boris3diamond-source/coingrid-releases/releases
   (аккаунт GitHub не нужен). Рядом лежит `.sha256` — контрольная сумма архива.
2. **Распакуйте** архив двойным щелчком и **перетащите `CoinGrid.app` в папку «Программы»**
   (Applications). Запускайте уже оттуда, а не из «Загрузок».
3. **Разрешите запуск.** Приложение не нотаризовано Apple, поэтому при первом запуске macOS его
   блокирует. Это нужно сделать один раз.

### Как разрешить запуск (macOS 15 Sequoia и новее)

**а.** Дважды щёлкните по Coin Grid в «Программах». Появится окно «Не удалось открыть „CoinGrid“»
(“CoinGrid” Not Opened). Нажмите **«Готово»** (Done). **Не нажимайте** «Переместить в Корзину»
(Move to Trash).

<img src="https://raw.githubusercontent.com/boris3diamond-source/coingrid-releases/main/docs/install/1-not-opened.png" width="340" alt="Окно «CoinGrid Not Opened», нажать Done">

**б.** Откройте  → **Системные настройки → Конфиденциальность и безопасность**
(System Settings → Privacy & Security). Прокрутите в самый низ, до раздела **«Безопасность»** (Security).
Под строкой «Разрешать приложения из» (Allow applications from) будет сообщение
«„CoinGrid“ заблокировано…» (“CoinGrid” was blocked to protect your Mac) — нажмите
**«Всё равно открыть»** (Open Anyway) и подтвердите паролем или Touch ID.

<img src="https://raw.githubusercontent.com/boris3diamond-source/coingrid-releases/main/docs/install/2-open-anyway.png" width="460" alt="Раздел Security, кнопка Open Anyway">

Сообщение показывается около часа после попытки запуска. Если его нет, повторите шаг «а».

**в.** Снова запустите Coin Grid. macOS спросит ещё раз — нажмите **«Всё равно открыть»** (Open Anyway).
Больше это окно появляться не будет.

### macOS 13–14

Щёлкните по `CoinGrid.app` в «Программах» **правой кнопкой → «Открыть» → «Открыть»**.

### Вместо шагов а–в: одна команда в Терминале

    xattr -dr com.apple.quarantine /Applications/CoinGrid.app

Команда сработает, только если приложение уже лежит в «Программах». Если оно в другой папке, наберите
`xattr -dr com.apple.quarantine ` (с пробелом в конце), перетащите `CoinGrid.app` в окно Терминала — путь
подставится сам — и нажмите Return.

После запуска в строке меню появится значок **CG**. Значка в Dock нет — так задумано.

## Разрешение «Запись экрана»

Нужно для Extract Edges и лупы (с версии 0.2.0). При первом использовании macOS попросит разрешение:
**Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука** (на macOS 13–14 — «Запись экрана») —
включите Coin Grid. Затем **полностью закройте** Coin Grid (меню CG → «Выйти») и запустите снова:
macOS применяет это разрешение только после перезапуска приложения.

Если после обновления Coin Grid лупа или Extract Edges «не видят» экран, хотя переключатель включён, —
удалите Coin Grid из этого списка кнопкой «−», добавьте снова и перезапустите приложение (или в Терминале:
`tccutil reset ScreenCapture com.coincheck.CoinGrid`). Так бывает со сборками без постоянной подписи.

## Шаблоны штемпелей (Trace)

Слепок Coin A сохраняется как файл `.dietrace` (меню CG → Trace → Сохранить, ⌘S) в
`~/Library/Application Support/CoinGrid/Templates/`. Файл можно переслать коллеге: двойной щелчок
открывает его в Coin Grid. Экспорт — прозрачный PNG, SVG и JSON координат (меню CG → Trace → Экспорт).

## Совмещение, контуры рельефа, presets (версия 0.3)

- **3-Point Align.** В TRACE инструментом «Опорные» (A) отметьте на Coin A 3–6 устойчивых точек подальше друг от
  друга и сохраните шаблон. На Coin B в COMPARE инструментом «B-точки» (B) щёлкните те же места в том же порядке и
  нажмите Enter: слепок встанет на монету (только перенос, поворот и равномерный масштаб). В палитре — RMS и невязка
  каждой пары в точках экрана; пунктир A → B показывает их на фото.
- **Extract Edges.** В TRACE обведите область инструментом ROI (R) и нажмите «Extract Edges»: Coin Grid снимет экран под
  областью (нужно разрешение «Запись экрана») и построит тонкие контуры рельефа цвета слепка. Preset'ы: «Мягкий» —
  резкое контрастное фото, только главные линии; «Стандарт» — обычное аукционное фото; «Чувствительный» — плоский свет,
  потёртая монета, слабый рельеф; «Тонкий» — мелкие детали при крупном увеличении. Совместите Coin Grid с монетой —
  тогда параметры подстраиваются под её размер на экране, и результат не зависит от увеличения в Preview.
- **Minutiae.** Кнопка «minutiae (эксп.)» у слоя контуров экспериментальная: на фото рельефа многие предложения —
  это разрывы или концы фрагментов контура, а не настоящие окончания штрихов, поэтому каждое нужно проверять глазами.
  Tab — следующее, Enter — принять, 1–5 — тип, Delete — отклонить. Отклонённые предложения запоминаются и повторно
  не предлагаются; неподтверждённые предложения не входят в экспорт PNG/SVG слепка, а в CSV/JSON координат
  попадают с пометкой `suggested`.
- **Линейка** (GRID, R): P1–P2 — расстояние (pt и % радиуса Coin Grid) и направление по циферблату, P3 — угол при P2;
  у каждой точки — r и θ от центра монеты. «Привязка к Coin Grid» притягивает точки к центру, окружностям и лучам сетки.
- **Presets** (палитра GRID и меню CG → Presets): сохранённая раскладка оверлея или только набор guides —
  `~/Library/Application Support/CoinGrid/presets.json`.
- **Overlay A/B** (⌃⌥A): две раскладки, например Coin Grid на Coin A и на Coin B.
- **Экспорт координат** (меню CG → Экспорт координат): CSV/JSON всех точек экрана — центр монеты, guides, линейка,
  точки слепка, опорные точки — с полярными координатами относительно центра Coin Grid; r и θ заполняются, только
  если Coin Grid видима, иначе остаются пустыми. Скрытые guides и скрытые группы слепка в экспорт не попадают.

## Обновление

Меню CG → «Проверить обновления…» открывает страницу релизов; текущая версия видна в том же меню.
Выйдите из Coin Grid, замените приложение в «Программах» новым и запустите его.

## Удаление

Перетащите `CoinGrid.app` в Корзину. Настройки удаляются командой
`defaults delete com.coincheck.CoinGrid`; шаблоны штемпелей (с версии 0.2.0) лежат в
`~/Library/Application Support/CoinGrid`.
